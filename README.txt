第一清潔工程行網站專案
======================

檔案說明
--------
index.html   網站首頁
style.css    網站外觀
script.js    手機選單與年份
assets/      圖片資料夾

如何預覽
--------
1. 解壓縮 ZIP。
2. 雙擊 index.html。
3. 瀏覽器會直接開啟網站。

如何放到網路
------------
最簡單方式可使用：
- Google Sites：適合初學者，但不能直接上傳整個 HTML 專案。
- GitHub Pages：免費，可直接發布這個專案。
- Netlify：免費方案可直接拖曳資料夾上傳。
- 一般虛擬主機：把所有檔案上傳到 public_html。
